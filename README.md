# MARKAS · Control de ingreso (local)

Uso diario: abrir `Registro_Ingreso_MARKAS.html` con Chrome. Sin internet, sin instalar nada.
Los datos se guardan en el navegador del dispositivo (usar siempre el mismo navegador y el mismo archivo).

Desarrollo: `npm install` · `npm run dev` · `npm run build` (genera dist/index.html)
Lista de invitados: `src/data/invitados.js`
